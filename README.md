# Sales Data Analysis Using Python

## Project Overview
This project analyses sample retail sales data using Python to identify revenue patterns, compare product performance, and evaluate sales across cities.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Features
- Creation and processing of a sales dataset
- Calculation of total revenue, quantity sold, and average sales per record
- Product-wise revenue analysis
- City-wise revenue analysis
- Data visualization using bar charts and a pie chart
- Export of analytical results to CSV files

## Key Findings
- Total revenue: ₹740,000
- Total quantity sold: 31 units
- Average revenue per record: ₹74,000
- Highest-revenue product: Laptop
- Highest-revenue city: Delhi

## How to Run
1. Install Python.
2. Install the required libraries using:
   `python -m pip install pandas numpy matplotlib seaborn`
3. Run `sales_analysis.py` using your configured Python interpreter.

## Dataset Note
The dataset is synthetic and was created for practice and demonstration. The findings do not represent actual business sales.

## Purpose
This project demonstrates basic data cleaning and processing, exploratory analysis, revenue calculations, data visualization, and reporting using Python.
